Parametric SVG paths optimized for 3D printing with a 0.4mm nozzle. Designed for 6x3mm keys. The engine generates continuous unbroken lines to prevent print failure on tiny text.

How to use in OpenSCAD

  1. Download a key's SVG by hovering over it and clicking the blue arrow.
  2. Place the `.svg` file in the same directory as your `.scad` script.
  3. The SVG internal canvas is 60x30mm to ensure high precision line data.
  4. Scale the import by [0.1, 0.1, 1] to shrink it exactly to your physical 6x3mm keycap dimensions.
  5. Use difference() to engrave the text, or union to emboss.
example.scad
// Example: Sinking the text into a 6x3mm keycap
difference() {
    cube([6, 3, 2], center = true); // Physical Keycap
    
    // Offset to top surface, center it, and shrink
    translate([-3, -1.5, 0.5])
    scale([0.1, 0.1, 1])
    linear_extrude(height = 1)
    import("key_LN.svg");
}
