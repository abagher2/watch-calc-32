# RP2040-Zero PCB Pinout & Wiring Plan

To test the connections on your custom PCB, map out exactly which GPIO pins connect to which components.

## 1. Pin Assignments (Modern Layout)

This pinout maps to the 43-key Modern matrix (8 rows x 6 columns) as generated by our KiCad config.

### OLED Display (I2C)
*   **VCC** -> 3.3V (Out)
*   **GND** -> GND
*   **SDA** -> GP0
*   **SCL** -> GP1

### Keyboard Matrix (6 Columns x 8 Rows)
The RP2040 will pull the 6 columns low sequentially and read the 8 rows to scan all 43 physical keys.

**Column Pins (Outputs):**
*   **Col 1** -> GP10
*   **Col 2** -> GP11
*   **Col 3** -> GP12
*   **Col 4** -> GP13
*   **Col 5** -> GP14
*   **Col 6** -> GP15

**Row Pins (Inputs with Pull-ups):**
*   **Row 1 (Top)** -> GP5
*   **Row 2** -> GP6
*   **Row 3** -> GP7
*   **Row 4** -> GP8
*   **Row 5** -> GP26
*   **Row 6** -> GP27
*   **Row 7** -> GP28
*   **Row 8 (Bottom)** -> GP29

---

## 2. Testing the Board
Once your PCB is manufactured and soldered, plug the RP2040-Zero into your computer via USB-C. 
Install **MicroPython** on it, and run the `board_test.py` script provided in this folder to verify all 43 keys register correctly.
